# CarenDMR UI Style Guide

## Ziel

CarenDMR wirkt wie eine moderne Funkkonsole, nicht wie ein technisches Testwerkzeug. Der DMR-Kern bleibt von der Darstellung getrennt.

## Farben

- Hintergrund: `#0B1220`
- Karten: `#111C2E`
- Eingabeflächen: `#18263A`
- Text: `#F4F7FB`
- Sekundärtext: `#8FA3BB`
- Empfang/Aktion: `#2F80ED`
- Verbunden: `#38D996`
- TX: `#D94141`
- Hinweis/QSO: `#F2C94C`

## Bedienregeln

- Rot wird ausschließlich für aktives TX und Fehler verwendet.
- Normale Betriebsereignisse erscheinen im Ereignisprotokoll, nicht als Dialog.
- Primäre Daten wie Rufzeichen, TG und Verbindungszustand sind aus Entfernung lesbar.
- Technische Einstellungen gehören nicht auf die Betriebsseite.
- Bezeichnungen: **TG wechseln**, **CONNECT**, **DISCONNECT**, **TX AUS**, **TX EIN**, **Stumm**.

## Komponenten

- Kanal-/Verbindungskarte
- Stationskarte
- Funksteuerungskarte
- Ereigniskarte
- Später: QSO-Karten und Einstellungsgruppen
